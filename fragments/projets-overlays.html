Cube

Ce programme en C pour calculatrice TI-83 Premium CE / TI-83 CE est un rasteriseur 3D minimaliste qui démontre l’affichage de graphiques 3D en temps réel sur un matériel très contraint.

Le cœur du programme repose sur un pipeline 3D simplifié : il définit un cube à l’aide de sommets dans l’espace 3D, applique des transformations de rotation autour de l'axe Y, puis projette ces points sur l’écran 2D de la calculatrice à l’aide d’une projection perspective.

Compétences utilisées :

  • Programmation C bas niveau sur architecture embarquée
  • Compréhension des bases d'un moteur 3D
  • Calculs de la projection perspective
  • Buffer Swapping pour un affichage fluide

Leds

Ce programme en C++ pour ESP32 est un contrôleur de bandeaux de LEDs WS2812B qui pilote deux bandeaux de 300 LEDs chacun, avec une architecture organisée et performante.

L'ESP32 expose une API que contrôle une interface web hébergée sur mon site personnel. Pour l'instant, elle permet d'allumer/éteindre les LEDs, de changer la couleur et de régler la luminosité. Comme les LEDs sont adressables individuellement, je pourrai facilement y ajouter des effets. Un capteur infrarouge est également intégré pour les piloter avec une télécommande.

Les LEDs et l'ESP32 sont câblés sur une alimentation 5V 40A.

Compétences utilisées :

  • Programmation C++ sur architecture embarquée (ESP32)
  • Conception d'une API embarquée sur l'ESP
  • Développement d'une interface web de contrôle

Terrain procédural

J'ai créé un générateur de terrain infini développé avec Godot Engine, visant à explorer les techniques de génération procédurale, et d'utilisation de noise maps dans un environnement 3D.

Le terrain est créé dynamiquement autour du joueur à l’aide de chunks chargés et déchargés automatiquement selon la position de la caméra. Chaque chunk est généré de manière procédurale à partir de bruit cohérent (Perlin + Fractales), ce qui permet une continuité naturelle du relief.

J’y ai également développé un générateur de routes procédural basé sur l’algorithme A* Le calcul des chemins s’appuie sur une carte de difficulté de déplacement dérivée du terrain (dénivelés, altitude, types de sol), afin de trouver le chemin le plus praticable.

Mis à jour mai 2026 : réécriture complète du système afin d’ajouter un système de biomes, d'instanciation de la végétation, les collisions et des appels directs au GPU pour des performances optimales, même sur des ordinateurs peu puissants.

Compétences utilisées :

  • Algorithmes de bruit (Perlin / Simplex)
  • Compréhension de l'algorithme de pathfinding A*

Serveur personnel sous Debian

Ce projet consiste à mettre en place un serveur sous Debian permettant d’héberger plusieurs services réseau et applicatifs afin de centraliser le stockage, le multimédia, l’automatisation et les outils de développement.

Services installés :

  • SSH : accès distant sécurisé au serveur pour l’administration en ligne de commande.
  • FTP / SFTP : transfert de fichiers entre le serveur et des machines clientes.
  • VPN : WireGuard et OpenVPN avec utilisateurs, pour accéder à mon réseau local depuis l’extérieur ou de mon téléphone.
  • Samba : partage de fichiers en réseau local compatible Windows et Linux, adapté au streaming vidéo.
  • Jellyfin : serveur multimédia pour le streaming de films, séries et musique.
  • Git : hébergement de dépôts de code pour le versioning et la collaboration, afin de ne plus être dépendant des limites de GitHub.
  • Pyload : gestionnaire de téléchargements automatisés.
  • FreshRSS : agrégateur de flux RSS auto-hébergé pour centraliser les actualités et ma veille informatique.
  • TeamSpeak : serveur vocal pour la communication en temps réel, chiffré et gratuit.
  • Syncthing : synchronisation automatique de projets et sauvegardes.
  • Bots Python : scripts automatisés pour diverses tâches et intégrations de développement.
  • Ollama (IA locale) : exécution de modèles d’intelligence artificielle en local sans cloud.

Un serveur personnel complet, pensé pour l’autonomie et le contrôle total de mon infrastructure, je réduis progressivement ma dépendance aux services cloud externes, tout en gardant un contrôle total sur mes données personnelles, leur stockage et leur sécurité.

Compétences utilisées :

  • Administration système Linux (Debian)
  • Sécurisation réseau
  • Conteneurisation Docker
  • Déploiement et maintenance de services self-hosted
